# Kronos Concierge

## Tech Stack
- React + Vite
- Tailwind CSS
- Django
- Django REST Framework

## Backend Setup
cd backend
python3 -m venv venv
source venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver


## Frontend Setup
cd frontend
npm install
npm run dev
